# 数学建模入门资料

本目录用于保存从 `zhanwen/MathModel` 仓库中挑选的数学建模学习资料。

## 建议优先保存

1. `数学建模应掌握的十类算法.md`：先建立知识地图。
2. `数学建模基础篇/第1章  建立数学模型.ppt`：了解建模的基本流程。
3. `数学建模基础篇/第2章  初等模型.ppt`：从简单案例开始练习。
4. `数学建模基础篇/第3章  简单的优化模型.ppt`：学习目标、约束和优化思想。
5. `数学建模基础篇/第4章  数学规划模型.ppt`：进入线性规划等常用模型。
6. `数学建模基础篇/第9章  概率模型.ppt`：补充随机问题建模基础。
7. `Matlab入门教程/Matlab入门.pdf`：熟悉基本计算工具。
8. `Matlab入门教程/MATLAB在数学建模中的应用.pdf`：学习如何把模型落地实现。
9. `数学建模算法/插值与拟合.pdf`：掌握数据建模的常用方法。
10. `数学建模算法/回归分析.pdf`：学习变量关系分析与预测。
11. `数学建模算法/线性规划.pdf`：掌握最常见的优化算法之一。
12. `数学建模算法/层次分析法.pdf`：学习基础评价与决策模型。
13. `数学建模算法/时间序列模型.pdf`：学习时间数据预测。
